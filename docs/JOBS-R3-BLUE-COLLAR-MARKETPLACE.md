# JOBS-R3 — 华人蓝领岗位优先市场

状态：IN_PROGRESS
前置条件：JOBS-R1: 10/10 PASS；JOBS-R2: 10/10 PASS
范围：仅美国；继续使用统一正式招聘数据源、统一账号、统一 /admin、统一 Web/APP，不建立第二套系统。

## 产品核心
唐人日报招聘求职不是传统复杂招聘网站，而是面向美国华人蓝领、新移民和英语能力有限用户的本地岗位信息市场。任何入口都必须先让用户看到工作岗位；企业发布是辅助动作，不得占据主入口。默认依靠已授权 GPS、账号保存的找工中心、IP 粗定位或用户手选地区推荐附近岗位；用户不会英文、不懂美国行政区划、不打字也应能完成找工。

## 固定10节点
1. 岗位优先入口：`/jobs/`、唐人日报首页招聘模块、APP 招聘入口均先展示岗位；不得先展示“我要招聘/我要求职”功能菜单。
2. 蓝领信息流：首页/专题页优先餐饮、装修建筑、物流仓库、司机、超市零售、美甲美容、家政护理等华人高频蓝领岗位；白领分类保留但不抢首屏。
3. 地理自动归类：发布者只填写自然语言地点（如“纽约法拉盛”“威斯康星麦迪逊”）；系统自动标准化到 State/City/County/Borough/Neighborhood、地图中心和对应栏目，不要求用户重复手选行政层级。
4. 三到四步极简发布：岗位名称/类别 → 地点 → 薪资与联系方式/工作说明 → 可选图片并发布。高级字段收起或由系统推断；发布者不得被迫理解美国行政区划。
5. 图片轻量发布：允许上传工作环境/店铺/招聘海报照片；图片可选，不影响正常发布和排序；继续移除不必要 EXIF 精确位置。
6. 一键联系：岗位卡和详情页优先提供电话直拨、短信/站内消息；允许在列表卡直接联系，不强迫先进入详情；聊天继续绑定具体岗位并纳入反诈骗治理。
7. IP/GPS/固定找工中心推荐：GPS 仅授权后使用；IP 仅粗粒度兜底；账号可保存最近找工中心；附近岗位优先，用户可随时切换其他州/城市/地区。
8. 中文地点与地图找工：搜索框允许中文地区俗称；地图支持州→城市→常用华人地区标签、拖动地图后“在这里找工作”；不会英文也可全程点选。
9. Web/APP/admin统一闭环：所有展示、发布、定位、联系、图片、状态和治理共用正式数据源；APP 与 Web 保持同一岗位排序逻辑和账号位置状态；/admin 同步可见。
10. 生产总验收：岗位优先、蓝领排序、自然语言地点、3-4步发布、图片、电话/消息、IP/GPS、中文地图、Web/APP/admin、隐私、安全、性能与 R1/R2 回归全部通过，才输出 `JOBS-R3: 10/10 PASS`。

## 硬规则
- 岗位永远在前，发布入口永远是辅助入口。
- 默认展示“附近工作/推荐工作”，不是“请选择你要做什么”。
- 不要求求职者会英文，不要求理解州/县/Borough/Neighborhood层级。
- 发布者填写一次地点后系统自动归类，不得再次要求重复选择同一地理信息。
- 发布岗位主流程最多3-4步；高级设置必须折叠或自动推断。
- 直接电话和站内消息必须明显、快速；能在岗位卡完成的动作不要强迫进入详情页。
- 保留R1/R2已有隐私、反诈骗、生命周期、稳定URL、账号同步和GPS授权边界。
