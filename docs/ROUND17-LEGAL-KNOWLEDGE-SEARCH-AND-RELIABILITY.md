# 第十七轮：法律知识检索、关联发现与生产可靠性

本轮固定10个节点，名称与顺序不得更改：

1. 法律站内搜索中文解析覆盖与相关性排序
2. 判例/新规多维筛选组合与可分享检索URL
3. 法律详情页相关判例/同机构规则关联发现
4. 案号、引证、机构与发布日期标准化展示
5. 法律数据库增量更新差异检测与重复记录治理
6. 中文解析完整率、事实约束与缺失回退治理
7. 法律页面移动端性能、无障碍与交互稳定性
8. 法律栏目生产错误监控、降级与恢复闭环
9. 法律SEO索引质量、Sitemap更新时效与内部链接完整性
10. 第十七轮最终生产总验收

## 第十七轮重新开始规则（严格统一版）

此前任何基于宽松覆盖标准产生的 PASS 全部作废。本轮从节点1重新验收，并以本文件当前版本为唯一验收标准。

## 总原则

- 第十七轮建立在第十六轮官方法律源、统一数据库、法律首页、13个联邦巡回法院导航、详情页和SEO基础之上，但所有第十七轮节点必须重新按严格标准验收。
- 第一方事实源继续限定为 SCOTUS、13个联邦巡回上诉法院、DOJ/EOIR BIA precedent decisions、White House Executive Orders、Federal Register API。
- BIA仅表示公开先例/precedent decisions，不得表述为“BIA全部裁决”。
- 不复制 Westlaw、Lexis 或其他商业法律数据库的编辑摘要、headnote或商业标注。
- 搜索结果相关性只能改变法律栏目内部结果排序，不得改变唐人日报首页既有新闻排序。
- 不得以AI生成内容替代官方案号、日期、机构、引证、官方链接或官方原文。
- 任何相关判例/规则推荐必须可追溯到统一法律数据库中的真实记录，不允许生成不存在的案例或规则。
- 数据去重不得通过删除无法确认的记录来伪造整洁；冲突记录必须保留可审计依据。
- 每个节点必须同时有代码级验收、数据级验收和生产证据后才算PASS；代码存在但未部署、数据未达标或生产未验证均不计完成。
- 不允许通过降低验收标准、容忍部分覆盖或使用“正在生成”作为完成状态获得PASS。
- 节点10必须重新验证1—9，只有日志明确输出 `ROUND 17: 10/10 PASS` 才能正式关闭本轮。

## 统一中文覆盖硬标准

- 统一法律数据库中每一条正式记录必须存在一条一一对应的中文内容记录；数据库有 N 条，则中文覆盖必须严格为 N/N = 100%。
- 当前数据库若为607条，则必须达到607/607；新增官方记录后分母自动增加，不允许继续使用固定163条或其他旧覆盖数作为PASS依据。
- 任何1条缺失都必须 FAIL；`coveragePct > 0`、`coveragePct >= 95`、抽样覆盖等宽松规则一律禁止。
- 前台正式生产状态不得对数据库内已发布记录显示“中文解析正在生成”“中文信息整理尚未生成”等占位文案。存在占位即节点6 FAIL，节点10不得PASS。
- 中文记录必须与官方记录通过 recordId 一一绑定，不得重复绑定、错绑、孤儿记录或跨版本错配。
- 中文标题、要旨、法律问题、裁判/规则、影响范围、来源依据必须完整；任何字段为空均FAIL。
- 中文内容必须忠实于官方来源，不得添加官方文本无法支持的案件事实、裁判理由、法律效果或预测结论。
- 对无法从当前官方材料确定的内容必须明确写“官方材料不足，无法确认”，不得猜测补齐。

## 一比一中文化标准

- 用户可见的核心法律信息必须实现逐条对应中文化：每条官方记录都必须有独立中文标题和完整结构化中文解释。
- 对可获取官方正文的记录，中文页面必须提供与官方正文内容结构对应的中文翻译/整理，不得只给一句摘要冒充完整中文内容。
- 原文段落、标题、核心规则、裁判结论不得遗漏或改变含义；允许为中文可读性调整语序，但不得改变法律含义。
- 官方原文始终保留并可直接访问；中文内容属于辅助理解层，不替代官方文本。

## 首页新闻统一规则（与本轮生产验收共同适用）

- 首页新闻模块正常生产读取必须使用统一实时已发布新闻入口；历史静态归档不得参与正常首页补位。
- 首页新闻新鲜度上限固定为4天；超过4天一律不得出现在首页新闻模块。
- 栏目只有1条或2条符合条件时就只显示1条或2条，禁止使用第5天及更早新闻凑满数量。
- 周末不发新闻不构成放宽4天规则的理由。
- 首页新闻仍按真实发布时间倒序，不得人为改变既有新闻排序逻辑。

## 节点1验收标准

节点1“法律站内搜索中文解析覆盖与相关性排序”必须满足：

- 搜索文本覆盖标题、案号、引证、发布机构、authority type、source system，以及对应中文解析的中文标题、要旨、法律问题、裁判/规则和影响范围。
- 精确标题/案号/引证命中优先于普通正文词命中；中文解析命中可参与排序但不得覆盖官方字段的高权重精确命中。
- 空查询继续保持发布日期优先的稳定默认排序。
- source/body/type筛选逻辑和13巡回法院状态保持不得回退。
- URL中的 q/source/body/type/page 状态必须继续可分享和恢复。
- 必须新增自动化审计，证明搜索覆盖与权重规则存在且不会改变首页新闻排序。

## 节点6硬性验收标准

节点6“中文解析完整率、事实约束与缺失回退治理”必须满足：

- `totalAnalyses === totalLegalRecords`。
- `coveragePct === 100` 且 `completeCoveragePct === 100`。
- orphan analyses = 0；duplicate record IDs = 0；metadata mismatch = 0；dataset version mismatch = 0。
- required fields缺失数 = 0；bad disclaimer = 0；commercial leak = 0；BIA overclaim = 0。
- 生产列表页和详情页对数据库正式记录不得出现缺失中文解析占位状态。
- 若数据库新增记录但中文内容尚未生成，则节点6立即重新FAIL，直到恢复100%覆盖。

## 节点10最终验收标准

- 必须重新执行节点1—9的最新严格审计，不能引用旧PASS。
- 必须确认中文覆盖为100%，且生产页面随机抽查与数据总量核对一致。
- 必须确认首页4天新闻新鲜度规则仍有效且没有历史静态补位回归。
- 只有全部满足后才允许输出：`ROUND 17: 10/10 PASS`。
