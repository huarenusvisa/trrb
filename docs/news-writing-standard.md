# 采写标准（发布者2026-10-02要求）
普通报道至少800个正文汉字，通常1200至1999字。深度稿沿用既定资料与字数要求。不得复制采集线索直接发布，不得发布末尾截断、重复正文或用免责声明填充的稿件。
美国时政稿必须写明美国在当前事件中的具体角色，并补充至少两项有来源的美国关联事实。优先原始报道、官方文件与直接当事人材料，核对日期、统计口径、流程和后续节点。第三国国内事件只有具有可核实的中国或美国实际关联才采编。不能为分类强行增加中美影响，不能用无关背景或模型记忆凑字。
资料不足可以在完成采写、准确归因和区分待核实事实后先发布，再由人工处理。此授权不能用于把原始线索、编辑提示或残句直接公开。证据不足的稿件不计入深度稿任务。
