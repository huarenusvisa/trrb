# 唐人财经 V1 开发规范与状态

## 仓库与分支
- Repository: `huarenusvisa/trrb`
- Development branch: `finance-v1-robinhood`
- 不主动合并或 rebase `main`，除非用户明确要求。

## 保护区（严禁修改）
财经开发默认仅修改 `finance/`，不得修改：
- `netlify.toml`
- SEO 脚本、SEO 诊断/验收脚本
- sitemap / Sitemap 文件与生成逻辑
- `.github/workflows` 中生产部署流程
- 与唐人财经无关的现有生产功能

## 产品定位
唐人财经是《唐人日报》的独立财经产品，采用行情驱动而不是新闻频道驱动。

- 信息架构参考：腾讯自选股
- 产品质感参考：Robinhood
- 不复制第三方代码、品牌素材或专有接口。
- 主色：白底 + `#00C805` 绿色体系 + 下跌/风险红 `#FF4D2E`
- 国际行情习惯：涨绿跌红
- 视觉目标：轻、净、现代、大数字、大图表、低装饰、高可读性。

## 一级导航
固定四栏：
1. 自选
2. 行情（默认入口）
3. 基金
4. 我的

“新闻”不作为一级入口，只作为行情、自选、基金、个股详情的解释层。

## V1 功能范围
### 行情
- 美股三大指数
- 市场时段状态与数据模式
- 行业热力图
- Top Movers
- Earnings / Upcoming / Macro
- Crypto 观察入口
- 市场新闻流

### 自选
- 全部 / 美股 / 中概股 / ETF / 港股 / 沪深
- 列表视图 + 热力视图
- 股票与 ETF/基金统一回流自选
- 本地添加/移除，不依赖账户

### 基金 / ETF
- 热门 ETF、指数、科技、黄金、半导体、跨境主题
- ETF 榜单
- 参数化基金详情：类别、费率、规模、风险、核心持仓、资讯
- 购买、申购、开户、KYC、交易保持隐藏

### 个股详情
- 名称、代码、当前价、日内涨跌、盘后数据
- 1D / 1W / 1M / 3M / YTD / 1Y / 5Y 图表
- 关键数据、新闻、分析师评级、财务、EPS、公告/SEC 接口位、热度、公司概览
- 加入自选、提醒、分享
- 不展示真实 Trade / 开户交易按钮

### 我的
- 本地自选状态
- 最近浏览
- 价格提醒列表
- 紧凑列表 / 动效偏好
- 清除浏览记录、关闭全部提醒、清除本机唐人财经数据
- 风险说明

## 数据策略
- `finance/data-adapter.js` 是统一数据适配层。
- 当前为明确标识的 demo/fallback 数据，不伪装实时行情。
- 未知股票/ETF 必须返回“未找到”，绝不回退成 AAPL/SPY 或其他资产。
- 页面必须显示 Demo / 非实时状态。
- 不硬编码 secrets。
- 真实行情、新闻、财报、评级未来必须使用合法授权、公开或合规数据源。

## 开发规则
每轮开发必须：
1. 读取 `finance-v1-robinhood` 当前状态。
2. 完成一个可验收的产品增量。
3. 优先只修改 `finance/`。
4. 检查 HTML / JS / 链接 / 移动端 / 无障碍基础问题。
5. 确认没有碰保护区。
6. 提交到 `finance-v1-robinhood`。
7. 更新本文件状态。
8. 缺 API / 密钥 / 牌照时使用适配层和明确 demo 数据继续，不阻塞 UI/工程开发。
9. 不创建或合并到 `main` 的 PR，除非用户明确要求。

### 第七轮：Premium 视觉精修
- 保留现有产品结构和交互，只升级高感知视觉层。
- 顶部导航改为更轻的高模糊玻璃层，搜索框聚焦反馈更接近原生金融 App。

- 热力图增加更高级的圆角、留白和触控反馈；Top Movers 改为更精致的浮层胶囊。

- 基金主题卡和账户卡统一高级轻阴影；新闻、自选和 ETF 列表增加克制 hover / active 反馈。
