# 唐人财经 V1 无人值守开发规范

## 仓库与分支
- Repository: `huarenusvisa/trrb`
- Development branch: `finance-v1-robinhood`
- 不主动合并或 rebase `main`，除非用户明确要求。

## 保护区（严禁修改）
无人值守开发期间不得修改以下区域：
- `netlify.toml`
- SEO 相关脚本、SEO 诊断/验收脚本
- sitemap / Sitemap 相关文件和生成逻辑
- 生产部署 workflow / `.github/workflows` 中的生产部署流程
- 与唐人财经无关的现有生产功能

默认仅在 `finance/` 目录内开发。若某项功能理论上需要跨目录改动，先采用 `finance/` 内的适配层、占位接口或独立资源解决，不等待用户确认，也不触碰保护区。

## 产品定位
唐人财经是《唐人日报》的独立财经产品，不做传统新闻频道式首页，而做行情驱动的移动端财经产品。

### 参考方向
- 信息架构参考：腾讯自选股
- 产品质感参考：Robinhood
- 不复制对方代码、品牌素材或专有数据接口，只参考交互结构、信息密度与视觉语言。

## 视觉规范
- 主底色：白色 `#FFFFFF`
- 品牌/上涨主绿：`#31C553`（可在同一绿色体系内细调）
- 下跌/风险红：`#FF4D3D`
- 主文字：接近黑色 `#111111`
- 次文字：中性灰
- 卡片：轻边框、较大圆角、充足留白
- 图表优先、大数字优先、减少装饰性元素
- 默认采用国际行情习惯：涨绿、跌红
- 视觉目标：接近 Robinhood 的轻、净、现代和高信息可读性，而不是腾讯式蓝色密集界面

## 一级导航
固定为四栏：
1. 自选
2. 行情
3. 基金
4. 我的

默认入口：`行情`

不设置“新闻”为一级导航。新闻必须嵌入行情、自选、基金和个股详情上下文。

## V1 页面与功能

### A. 行情首页（默认首页）
优先级最高。
- 美股三大指数：道琼斯、纳斯达克、标普500
- 市场状态与更新时间
- 行业/板块热力图（Robinhood 风格）
- Top Movers：涨幅、跌幅、异动
- Earnings：财报日历、已公布/即将公布
- Macro / Upcoming 预留
- ETF 热点
- 市场新闻流
- 新闻仅作为行情解释层，不独立占一级入口

### B. 自选
- 分类：全部 / 美股 / ETF / 中概股 / 港股 / 沪深 / 基金
- 名称、代码、小走势图、最新价、涨跌幅
- 支持列表视图
- 逐步增加热力图视图与筛选/排行视图
- 自选相关的新闻、公告、财报提醒放在列表之后
- 添加/移除自选先使用本地存储或前端状态，不依赖真实账户

### C. 基金 / ETF
- 热门 ETF
- 指数 ETF
- 行业/主题 ETF
- 黄金与大宗商品 ETF
- 跨境 ETF
- ETF/基金榜单
- 基金详情页预留：基础资料、费用、规模、历史表现、持仓、相关资讯、风险说明
- 购买、申购、开户、KYC、交易入口默认隐藏

### D. 个股详情
参考腾讯的信息完整度 + Robinhood 的视觉。
- 股票名称、代码、当前价、日内涨跌、盘后数据
- 大尺寸价格图表
- 1D / 1W / 1M / 3M / YTD / 1Y / 5Y / Advanced
- 关键数据
- 新闻
- 公司概览
- 财务数据与趋势图
- Earnings / EPS
- Analyst ratings
- Short interest
- Trading trends / 热度数据
- 公告/SEC 来源预留
- 底部公开动作：加入自选、提醒、分享
- 不展示真实 Trade / 开户交易按钮

### E. 我的
- 未登录状态也可用
- 自选本地同步状态
- 浏览记录
- 提醒
- 偏好设置
- 数据显示设置
- 关于/风险提示
- 未来账户、开户与投资服务模块继续由 feature flag 隐藏

## 数据策略
- V1 首先保证产品结构、交互和视觉完整。
- 在没有第三方 API 密钥时，不阻塞开发：建立统一数据适配层 + demo/fallback 数据。
- 不硬编码任何密钥，不提交 secrets。
- 实时行情、新闻、财报、分析师评级等未来必须从合法授权、公开或合规的数据源接入。
- 不复制腾讯、Robinhood 的专有数据接口。

## 无人值守开发规则
每次自动开发运行必须：
1. 检查 `finance-v1-robinhood` 当前状态和最近提交。
2. 阅读本文件，识别尚未完成的最高优先级任务。
3. 每次完成一个有意义、可验收的增量，不做无意义格式化提交。
4. 优先只修改 `finance/`。
5. 做基础静态检查：HTML 结构、JS 语法、链接、移动端布局、明显可访问性问题。
6. 检查没有误改保护区。
7. 将修改提交到 `finance-v1-robinhood`。
8. 更新本文件下方的“开发状态”。
9. 不向用户询问 UI 细节；在既定风格内自行选择专业默认方案。
10. 若缺第三方 API/密钥/牌照信息，则记录为“外部依赖”，使用适配层或 demo 数据继续做其他部分。
11. 不创建或合并到 `main` 的 PR，除非用户明确要求。

## V1 完成标准
只有同时满足以下条件才标记 V1 Complete：
- 四个一级页面均可正常切换并具备完整移动端布局
- 行情默认首页完成并达到 Robinhood 式视觉质感
- 自选列表可交互，至少本地添加/移除状态可工作
- 个股详情至少有一套完整模板并可由股票代码参数化或扩展
- 基金/ETF 页面具备可用的信息层级和详情入口
- “我的”具备基本偏好/记录/提醒结构
- 新闻已嵌入行情、自选和个股上下文
- 手机宽度 360–430px 无明显横向溢出
- 桌面端有合理响应式布局
- 交易/开户/基金购买功能仍保持隐藏
- 无改动保护区
- 无硬编码 secrets
- 代码具备后续接入真实数据源的清晰位置
