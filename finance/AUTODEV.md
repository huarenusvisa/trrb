# 唐人财经 V1 开发规范与状态

## 仓库与分支
- Repository: `huarenusvisa/trrb`
- Development branch: `finance-v1-robinhood`
- 不主动合并或 rebase `main`，除非用户明确要求。

## 保护区（严禁修改）
财经开发默认仅修改 `finance/`，不得修改：
- `netlify.toml`
- SEO 脚本、SEO 诊断/验收脚本
- sitemap / Sitemap 文件与生成逻辑
- `.github/workflows` 中生产部署流程
- 与唐人财经无关的现有生产功能

## 产品定位
唐人财经是《唐人日报》的独立财经产品，采用行情驱动而不是新闻频道驱动。

- 信息架构参考：腾讯自选股
- 产品质感参考：Robinhood
- 不复制第三方代码、品牌素材或专有接口。
- 主色：白底 + `#00C805` 绿色体系 + 下跌/风险红 `#FF4D2E`
- 国际行情习惯：涨绿跌红
- 视觉目标：轻、净、现代、大数字、大图表、低装饰、高可读性。

## 一级导航
固定四栏：
1. 自选
2. 行情（默认入口）
3. 基金
4. 我的

“新闻”不作为一级入口，只作为行情、自选、基金、个股详情的解释层。

## V1 功能范围
### 行情
- 美股三大指数
- 市场时段状态与数据模式
- 行业热力图
- Top Movers
- Earnings / Upcoming / Macro

### 自选
- 全部 / 美股 / 中概股 / ETF / 港股 / 沪深

### 个股详情
- 名称、代码、当前价、日内涨跌、盘后数据
- 1D / 1W / 1M / 3M / YTD / 1Y / 5Y 图表

- 加入自选、提醒、分享
- 不展示真实 Trade / 开户交易按钮

### 我的
- 本地自选状态
- 最近浏览
- 价格提醒列表
- 紧凑列表 / 动效偏好
- 清除浏览记录、关闭全部提醒、清除本机唐人财经数据
- 风险说明

## 数据策略
- `finance/data-adapter.js` 是统一数据适配层。
- 当前为明确标识的 demo/fallback 数据，不伪装实时行情。
- 未知股票/ETF 必须返回“未找到”，绝不回退成 AAPL/SPY 或其他资产。
- 页面必须显示 Demo / 非实时状态。
- 不硬编码 secrets。
- 真实行情、新闻、财报、评级未来必须使用合法授权、公开或合规数据源。

## 开发规则
每轮开发必须：
1. 读取 `finance-v1-robinhood` 当前状态。
2. 完成一个可验收的产品增量。
3. 优先只修改 `finance/`。
4. 检查 HTML / JS / 链接 / 移动端 / 无障碍基础问题。
5. 确认没有碰保护区。
6. 提交到 `finance-v1-robinhood`。
7. 更新本文件状态。
8. 缺 API / 密钥 / 牌照时使用适配层和明确 demo 数据继续，不阻塞 UI/工程开发。
9. 不创建或合并到 `main` 的 PR，除非用户明确要求。

### 第十四轮：真实产品韧性与短屏收口
- 新增 `resilience.css` / `resilience.js`，作为首页、个股和 ETF 共用的弱网、异常和空状态恢复层。
- 主页面超过约 4.5 秒仍未完成核心渲染时显示明确恢复条，并提供“重新载入”，不使用其他股票或 ETF 数据冒充失败资产。
- 数据适配层没有加载时给出专门提示；离线/恢复在线时恢复条会同步更新网络状态。
- 主内容使用 `aria-busy` 标记加载生命周期，并自动加入键盘可见的“跳到主要内容”入口。
- 自选为空时提供“搜索添加自选”；空分类提供“查看全部自选”；ETF 空主题提供“查看全部 ETF”；最近浏览和价格提醒空状态也增加明确下一步。
- 360–430px 短屏进一步压缩详情页标题、价格、图表和分区间距；680px 以下高度和手机横屏有独立图表高度保护。
- 韧性层由现有 `product-polish.js` 和 `detail-navigation.js` 自动加载，不改写主业务逻辑，不开放任何交易或开户能力。
- 已同步到 `finance-v1-preview`。本轮仅做静态代码复核，未将 iPhone / PC 实际浏览器验收标记为通过。

### 第十五轮：详情来源返回与会话级状态记忆
- 新增 `navigation-memory.js`，以 sessionStorage 记录当前一级页面、行情 Tab、自选分类、ETF 主题筛选和进入详情前的滚动位置。
- 从行情、自选、基金或搜索进入股票 / ETF 详情时自动记录来源；详情页返回按钮不再固定写死“返回自选”。
- 个股与 ETF 顶部返回按钮会根据实际来源自动标记“返回行情 / 返回自选 / 返回基金 / 返回我的”，ETF 底部返回按钮同步更新。
- 返回时优先使用浏览器原生 history，便于 BFCache 保留真实 DOM 与滚动位置；需要重新载入首页时使用保存上下文恢复来源页面和滚动位置。
- 行情 Tab、自选分类、基金主题仅做本次 session 级记忆，不永久锁定用户下次打开时的默认选择。
- 详情页自身滚动不会覆盖首页保存的滚动位置；未知 ETF 也会根据 `fund.html` 路径正确回到基金，而不是误判为股票。
- `product-polish.js` 与 `detail-navigation.js` 只负责加载和使用导航记忆层，未改变行情数据、交易边界或一级架构。
- 已同步到 `finance-v1-preview`。本轮完成静态逻辑复核，但仍未把 iPhone / PC 真机往返验收标记为通过。

## 当前结论
当前仍定义为 **V1 Candidate+**。四个一级页面、个股和 ETF 详情已经形成一致的高级视觉与交互语言，主要假交互、空状态、弱网失效路径和详情返回上下文已逐步收口。下一阶段仍以实际 iPhone / PC 一屏一屏验收、Lighthouse 运行时检查和极少量问题修复为主，完成后再标记 `V1 Complete`。
